# Projet d'exemple : la pizzeria

Un mini-projet **fictif**, jamais exécuté, qui sert de terrain à `exemple-visite.json`.

Trois services : `client` (le navigateur), `api` (reçoit et suit les commandes) et `cuisine` (prépare les pizzas, puis prévient l'API).

Pour régénérer la page d'exemple : copie `exemple-visite.json` sous le nom `visite.json` dans un dossier de ton choix, puis lance depuis la racine du dépôt :

```
node assembler.mjs <ce-dossier> exemple
```

La page `visite.html` apparaît dans ce dossier.
